# BlackBox demo clips

Short narrated clips of BlackBox on Joget 8.2. Start with the first one; each later clip covers one part of it in
more detail.

| Clip | What it shows | Length | For |
|---|---|---|---|
| [hero.mp4](hero.mp4) | **The bug nobody could reproduce.** Cat's leave request fails. She records it with BlackBox and sends the downloaded file to an outside support team, who find the cause and send a one-line fix. | 1:07 | Anyone new to BlackBox |
| [app.mp4](app.mp4) | **Her app, not just her screen.** The recording includes the app she used, with her data masked. The support team imports it on their own Joget and gets the same error. | 0:51 | Support and app teams |
| [replay.mp4](replay.mp4) | **Read a replay.** One clue at a time on the replay page (timeline, Next issue, server log lines, network, Info → Changes in the last 7 days), joined into the cause. | 0:54 | Support and app teams |
| [slow.mp4](slow.mp4) | **Slow, not broken.** A page takes ten seconds. The recording shows 200 OK, a calm server and a Glowroot trace pointing at a query on a column with no index; one change makes it fast. | 0:55 | IT and ops teams |
| [setup.mp4](setup.mp4) | **Set it up, safely.** An admin installs the plugin, chooses who can upload and who sees server data, and loads the extension; a test recording shows up on the server. | 1:22 | Joget admins |
