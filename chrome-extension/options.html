BlackBox settings

The BlackBox upload endpoint of the server that stores recordings. Uploads use your login on that server in this browser.

Opened by Open uploaded. {id} is replaced with the recording's id on the server.

When a recording stops and you are logged in to the Upload URL's server, it is uploaded (page title as the title, no notes) and the server's replay page opens, with the system logs, traces and server load. Not logged in: it replays here, and you can upload it later. Saved as soon as you tick or untick it.

For all BlackBox pages in the extension and on the Upload URL's server. Downloaded HTML files and the standalone viewer have their own Text size picker.

For all BlackBox pages in the extension and on the Upload URL's server. Downloaded HTML files and the standalone viewer have their own Theme picker.
